# Smart Campus Event & Facility Booking System

This project implements a beginner-friendly Python application for managing campus facility bookings.

## Run the app

From the project root:

python main.py

## Included features

- View available facilities
- Submit a reservation request
- Track reservation status
- Approve or reject pending reservations
- Cancel reservations

## Structure

- SmartCampusBooking/main.py: main console menu
- SmartCampusBooking/models: data classes and enums
- SmartCampusBooking/services: facility and event managers
- SmartCampusBooking/use_cases: each use case in its own file
